# Python Classes and Objects

This project contains Python scripts demonstrating Object-Oriented Programming (OOP) concepts.

## Learning Objectives

- Understand what OOP is
- Learn about classes and objects
- Understand the difference between classes and instances
- Work with attributes and methods
- Use special methods like `__init__`
- Understand data abstraction, encapsulation, and information hiding
- Work with properties and getters/setters
- Use `__dict__` and `getattr`

## Files

- `0-square.py` - Empty Square class definition

## Requirements

- Python 3.8.5
- Ubuntu 20.04 LTS
- pycodestyle 2.7.*

## Usage

Run the main script:
```bash
python3 0-main.py
```

Check code style:
```bash
pycodestyle 0-square.py
```
