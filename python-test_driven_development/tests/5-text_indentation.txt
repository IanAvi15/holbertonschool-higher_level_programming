============================
How to use text_indentation
============================

This module provides a function that prints text with indentation after
punctuation marks.

Using ``text_indentation``
==========================

Import the function:

    >>> text_indentation = __import__('5-text_indentation').text_indentation

Simple text with period:

    >>> text_indentation("Hello. World")
    Hello.
    <BLANKLINE>
    World

Text with question mark:

    >>> text_indentation("How are you?")
    How are you?
    <BLANKLINE>

Text with colon:

    >>> text_indentation("Note: important")
    Note:
    <BLANKLINE>
    important

Multiple punctuation marks:

    >>> text_indentation("Hello. How are you? Great:")
    Hello.
    <BLANKLINE>
    How are you?
    <BLANKLINE>
    Great:
    <BLANKLINE>

Text with no punctuation:

    >>> text_indentation("Hello world")
    Hello world

Single period:

    >>> text_indentation(".")
    .
    <BLANKLINE>

Single question mark:

    >>> text_indentation("?")
    ?
    <BLANKLINE>

Single colon:

    >>> text_indentation(":")
    :
    <BLANKLINE>

Text with spaces after punctuation:

    >>> text_indentation("Hello.   World")
    Hello.
    <BLANKLINE>
    World

Text with multiple spaces:

    >>> text_indentation("Hello   world")
    Hello   world

Consecutive punctuation:

    >>> text_indentation("End.. Start")
    End.
    <BLANKLINE>
    .
    <BLANKLINE>
    Start

Empty string:

    >>> text_indentation("")

Text with newlines:

    >>> text_indentation("Hello\nWorld")
    Hello
    World

Long text:

    >>> text_indentation("This is a test. Another sentence? Yes: continue")
    This is a test.
    <BLANKLINE>
    Another sentence?
    <BLANKLINE>
    Yes:
    <BLANKLINE>
    continue
