========================
How to use say_my_name
========================

This module provides a function that prints a person's full name.

Using ``say_my_name``
=====================

Import the function:

    >>> say_my_name = __import__('3-say_my_name').say_my_name

Basic usage with first and last name:

    >>> say_my_name("John", "Smith")
    My name is John Smith

Another example with first and last name:

    >>> say_my_name("Walter", "White")
    My name is Walter White

Using default last_name (empty string):

    >>> say_my_name("Bob")
    My name is Bob 

Single character names:

    >>> say_my_name("A", "B")
    My name is A B

Names with spaces:

    >>> say_my_name("Jean", "Claude")
    My name is Jean Claude

Empty first name with last name:

    >>> say_my_name("", "Smith")
    My name is  Smith

Both names empty:

    >>> say_my_name("", "")
    My name is  

Long names:

    >>> say_my_name("Christopher", "Alexander")
    My name is Christopher Alexander
