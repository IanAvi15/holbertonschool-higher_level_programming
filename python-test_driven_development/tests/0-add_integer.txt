===========================
How to use 0-add_integer.py
===========================

This module provides an integer addition function that handles integers and floats.

Using ``add_integer``
=====================

The function takes two parameters: ``a`` (required) and ``b`` (optional, defaults to 98).

Basic addition with two integers:
    >>> add_integer = __import__('0-add_integer').add_integer
    >>> add_integer(1, 2)
    3

Adding with a negative integer:
    >>> add_integer(100, -2)
    98

Using the default value for b:
    >>> add_integer(2)
    100

Adding a float and an integer (float is casted to int):
    >>> add_integer(100.3, -2)
    98

Adding two floats (both casted to integers):
    >>> add_integer(10.5, 20.7)
    30

Negative float addition:
    >>> add_integer(-5.8, -3.2)
    -8

Large numbers:
    >>> add_integer(1000000, 2000000)
    3000000

Float with default b parameter:
    >>> add_integer(50.9)
    148

Zero values:
    >>> add_integer(0, 0)
    0

    >>> add_integer(0)
    98
