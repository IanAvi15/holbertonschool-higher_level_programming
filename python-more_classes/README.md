# Python - More Classes and Objects

This project contains Python scripts demonstrating advanced Object-Oriented Programming (OOP) concepts.

## Learning Objectives

- Understand why Python programming is awesome
- Learn about OOP and "first-class everything"
- Understand classes, objects, and instances
- Work with public, protected, and private attributes
- Understand `self` and methods
- Use special methods like `__init__`, `__str__`, and `__repr__`
- Learn about Data Abstraction, Data Encapsulation, and Information Hiding
- Understand properties and the Pythonic way to write getters and setters
- Work with class attributes and class methods
- Learn about static methods
- Understand `__dict__` and attribute lookup
- Use the `getattr` function

## Files

- `0-rectangle.py` - Empty Rectangle class definition

## Requirements

- Python 3.8.5
- Ubuntu 20.04 LTS
- pycodestyle 2.7.*

## Usage

Run the main script:
```bash
python3 0-main.py
```

Check code style:
```bash
pycodestyle 0-rectangle.py
```
